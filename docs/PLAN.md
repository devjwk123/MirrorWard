# smartTV 기획서

갤럭시 노트20을 HDMI로 빔프로젝터에 연결해 스마트 TV로 쓰고, Xbox 게임패드 하나로 모든 것을 조작하는 프로젝트.

## 1. 목적

- PC를 켜고 게임을 실행하는 번거로움 제거
- PC를 켜고 넷플릭스를 실행하는 번거로움 제거
- 마우스/키보드 없이 **Xbox 게임패드만으로** 모든 조작

## 2. 하드웨어 구성

| 구성품 | 역할 |
|---|---|
| 갤럭시 노트20 | 본체 (스마트 TV 역할) |
| USB-C → HDMI 어댑터/케이블 | 노트20 → 빔프로젝터 영상 출력 |
| 빔프로젝터 | 디스플레이 |
| Xbox 게임패드 (블루투스) | 유일한 입력 장치 |
| 게임용 노트북 | Steam 게임 실행, Steam Link 호스트 |

## 3. 핵심 기능

1. **TV 런처(홈 화면)**: 게임패드로 조작하는 큰 타일형 UI
2. **앱 바로가기**: 넷플릭스, 유튜브, 인터넷(브라우저), 안드로이드 게임
3. **PC 게임 타일**: Steam 게임을 홈 화면에 표시, 선택 즉시 실행
4. **원클릭 PC 게임**: 타일 선택 → PC 자동 켜기 → 게임 실행 → Steam Link 자동 연결 (PC가 이미 켜져 있으면 바로 연결)
5. **게임패드 컨트롤**: 유튜브/넷플릭스/인터넷을 패드로 쉽게 조작

## 4. 구현 방식

### 4.1 One UI 대체 → 커스텀 런처 앱 (권장)
One UI 자체를 교체하려면 부트로더 언락 + 커스텀 ROM이 필요하고, 보증/Knox/보안 앱 문제가 생긴다. 대신 **홈 화면 런처 앱**을 만들어 기본 홈으로 지정하면 사실상 One UI를 대체한 경험을 얻을 수 있다.
- 1단계는 런처 앱으로 진행, 커스텀 ROM은 추후 검토

### 4.2 화면 출력
- USB-C(DisplayPort Alt Mode) → HDMI. 노트20은 지원
- 미러링 모드 vs 삼성 DeX(데스크톱) 모드 중 선택 필요 → 런처는 TV 해상도/가로 화면 기준으로 설계

### 4.3 게임패드 조작 (앱별)
- 런처: 방향키/A/B 포커스 이동 방식(리모컨 UX)
- 유튜브/넷플릭스: 공식 앱은 터치 위주 → 접근성 서비스(AccessibilityService)로 패드 입력을 탭/스와이프로 변환하는 "패드 → 터치" 매핑 레이어
- 인터넷: 커서 모드(스틱으로 포인터, 트리거로 스크롤) 또는 포커스 이동 기반 브라우저

### 4.4 Steam Link 원클릭 구동
구성 요소:
- **노트20 런처**: 게임 목록 표시, 타일 선택 시 아래 순서 실행
- **PC 에이전트(노트북 상주 프로그램)**: 게임 목록 제공, 게임 실행 명령 수신
- 흐름:
  1. 런처가 PC 상태 확인 (에이전트 ping)
  2. 꺼져 있으면 **Wake-on-LAN** 매직 패킷 전송 후 부팅 대기
  3. 에이전트가 `steam://rungameid/<appid>`로 게임 실행 (Steam 자동 로그인 필요)
  4. 런처가 Steam Link 앱으로 해당 PC에 스트리밍 연결
- 게임 목록/아이콘: Steam 로컬 라이브러리 + 에이전트 API로 노트20에 전달

## 5. 기술 리스크 / 확인 필요 사항

| 리스크 | 내용 | 대응 |
|---|---|---|
| Wake-on-LAN | 노트북은 **Wi-Fi로는 WoL이 대부분 안 되고**, 완전 종료(S5) 상태에서는 유선 LAN도 제한적. 절전(sleep) 상태 복귀는 비교적 잘 됨 | 노트북 유선 LAN 연결 + BIOS WoL 설정 확인, 안 되면 절전 상태 유지 방식 사용 |
| Steam 자동 로그인 | 부팅 후 Windows/Steam 자동 로그인 필요 | Windows 자동 로그인, Steam 시작 프로그램 등록 |
| Steam Link 자동 연결 | Steam Link 앱이 특정 게임으로 직접 딥링크되는 공식 기능은 없음 | PC 에이전트가 게임 실행 + Steam Link는 호스트 자동 연결(마지막 호스트) 방식으로 해결 |
| 넷플릭스 HDMI 출력 | DRM(Widevine) 때문에 미러링 시 화질 제한/블랙 화면 가능 | 초기에 실기기로 먼저 테스트 |
| 발열/충전 | 장시간 영상 출력 + 충전 시 발열 | 충전 동시 지원 어댑터(PD 패스스루) 사용 |
| 접근성 서비스 | 앱 조작 자동화는 Play 스토어 정책 이슈 가능 | 개인 사용 목적(사이드로드)으로 한정 |
| 노트북 사양 | 스트리밍 인코딩 성능(NVENC 등) | 사용할 노트북 GPU 확인 |

## 6. 단계별 로드맵

- **Phase 0 – 검증 (PoC)**: HDMI 출력, Xbox 패드 연결, 넷플릭스 화질, Steam Link 지연시간, 노트북 WoL 가능 여부 테스트
- **Phase 1 – 런처 MVP**: 게임패드로 이동 가능한 홈 화면, 넷플릭스/유튜브/브라우저/안드로이드 게임 바로가기
- **Phase 2 – 패드 조작 레이어**: 앱별 패드 → 터치 매핑, 브라우저 커서 모드
- **Phase 3 – PC 게임 연동**: PC 에이전트 개발, 게임 목록 동기화, WoL, 자동 실행/연결
- **Phase 4 – 완성도**: 부팅 시 자동 시작, 절전/화면 꺼짐 관리, UI 다듬기, (선택) 커스텀 ROM 검토

## 7. 제안 기술 스택 (확정 아님)

- 노트20 런처: Android 네이티브 (Kotlin + Jetpack Compose / TV용 포커스 처리)
- PC 에이전트: Windows 백그라운드 프로그램 (Python 또는 C#), 로컬 네트워크 REST API
- 통신: 같은 Wi-Fi/LAN 내 HTTP + WoL UDP 패킷
